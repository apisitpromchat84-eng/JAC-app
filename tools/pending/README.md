## Topic A — HIVP管 vs HT管 (seen in exam 2026-10-17)  — older set, one pipe per stem (Apisit said the real one was not like this)
h1 HIVP管の正式な名称 → 耐衝撃性硬質ポリ塩化ビニル管 (distractor 耐熱性…)
h2 HT管の特徴として正しいもの → 赤茶色・給湯や温泉配管
h3 HIVP管の説明で誤っているもの → 熱に強いので温泉配管に適している
h4 寒冷地・衝撃を受けやすい場所の給水管に適した塩ビ管 → HIVP管
h5 種類と色の組み合わせ → HIVP 濃い青 / HT 赤茶色
h6 一般の塩ビ管の弱点を改良した組み合わせ → 衝撃に弱い→HIVP、熱に弱い→HT

## Topic B — 道路使用許可: who applies (seen in exam 2026-10-16) — not picked yet
p1 道路使用許可を受けなければならないのは誰 → 道路で工事をしようとする者、またはその請負人
p2 申請先 → 所轄の警察署長
p3 道路に物件を継続設置 → 道路占用許可 ― 道路管理者
p4 道路占用許可を受けなければならないのは誰 → 物件を設置しようとする者
p5 道路使用許可で作業、正しくないもの → 交通整理員を配置しなくてもよい (trap なくてもよい)
note: JAC text ties the permit to 作業責任者 (携行); law says 工事をする者・請負人 applies — avoid putting both as options.
